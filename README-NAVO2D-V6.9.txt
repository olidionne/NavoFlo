Navo2D V6.9 — AutoCAD-first dimension + compact ribbon pass

- Compact stacked ribbon inspired by AutoCAD panels.
- Semantic dimension groups: one click selects the complete dimension.
- Angular dimension grip moves the arc inward/outward.
- Radius/diameter text grip rebuilds a real dogleg leader.
- Filled, smaller adaptive arrowheads.
- Arrow placement modes: Auto / Inside / Outside; right-click or double-click a dimension to change.
- Dimension properties: precision, text scale, arrow scale.
- Existing V6.8 ROTATE Copy/Reference workflow retained.
- Dimensions still export as R12-safe primitives on DIMENSIONS layer.

Important: this is an AutoCAD-parity pass for the commands Navo2D currently implements; it is not a claim of complete AutoCAD command coverage.
